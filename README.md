# Blinkit-Sales-Analysis-PowerBI
Interactive Blinkit sales analysis dashboard built using Power BI, DAX, Power Query, and data visualization.

# 🛒 Blinkit Sales Analysis Dashboard

## 1. Project Title / Headline

### 🛒 Blinkit Sales Analysis: Interactive Power BI Dashboard

An interactive Power BI dashboard designed to analyze Blinkit's sales performance, outlet characteristics, product categories, customer ratings, and key business metrics.

---

## 2. Short Description / Purpose

The Blinkit Sales Analysis Dashboard is an interactive Power BI report developed to provide a comprehensive view of sales performance across different product categories, outlet types, outlet sizes, outlet locations, and fat-content categories.

The dashboard transforms raw sales data into meaningful KPIs and visual insights that help users understand sales patterns and outlet performance.

---

## 3. Tech Stack

The dashboard was developed using the following tools and technologies:

- 📊 **Power BI Desktop** – Main platform used to create the interactive dashboard and visualizations.
- 📁 **Power Query** – Used for data cleaning, transformation, and preparation.
- 🧮 **DAX** – Used to create calculated measures and perform business calculations.
- 🗂️ **Data Modeling** – Used to organize and structure the data for analysis.
- 📈 **Power BI Visualizations** – Used to present KPIs, trends, comparisons, and category-level analysis.

---

## 4. Data Source

The project uses the **Blinkit sales dataset**, containing information about products, sales, outlet characteristics, item types, fat content, outlet location, outlet size, outlet establishment, and customer ratings.

### Dataset includes information such as:

## 5. Features / Highlights

### 🔹 Business Problem

Blinkit generates sales across different products and outlet types, but analyzing raw sales data directly can make it difficult to identify important sales patterns and performance differences.

The objective of this project is to transform the raw data into an interactive dashboard that provides a clear view of the business performance.

### 🔹 Goal of the Dashboard

The main goal is to analyze:

- Overall sales performance
- Product category performance
- Outlet performance
- Customer ratings
- Outlet size and location performance
- Fat-content contribution to sales

### 🔹 Key Performance Indicators

The dashboard provides the following KPIs:

- 💰 **Total Sales**
- 📊 **Average Sales**
- 📦 **Number of Items**
- ⭐ **Average Rating**

### 🔹 Dashboard Visuals

The dashboard includes:

- Total Sales by Fat Content
- Total Sales by Item Type
- Fat Content by Outlet
- Total Sales by Outlet Establishment
- Sales by Outlet Size
- Sales by Outlet Location
- Metrics by Outlet Type

### 🔹 Interactive Features

- 🎛️ Interactive slicers
- 🔄 Clear-all/reset filters button
- 🏠 Page navigation
- 📅 Calendar navigation element
- ❓ Power BI Q&A functionality
- 📊 Interactive charts and KPI cards

## 6. Business Requirements

### KPI Requirements

1. **Total Sales**  
   The overall revenue generated from all items sold.

2. **Average Sales**  
   The average revenue generated per sale.

3. **Number of Items**  
   The total number of items sold.

4. **Average Rating**  
   The average customer rating for the items sold.

### Chart Requirements

1. **Total Sales by Fat Content**
   - Objective: Analyze the impact of fat content on total sales.
   - Chart Type: Donut Chart.

2. **Total Sales by Item Type**
   - Objective: Identify the performance of different item types.
   - Chart Type: Bar Chart.

3. **Fat Content by Outlet**
   - Objective: Compare total sales across outlets segmented by fat content.
   - Chart Type: Stacked Column Chart.

4. **Total Sales by Outlet Establishment**
   - Objective: Evaluate how outlet establishment influences total sales.
   - Chart Type: Line Chart.

5. **Sales by Outlet Size**
   - Objective: Analyze the relationship between outlet size and total sales.
   - Chart Type: Donut / Pie Chart.

6. **Sales by Outlet Location**
   - Objective: Assess the geographic distribution of sales.
   - Chart Type: Funnel / Map.

7. **All Metrics by Outlet Type**
   - Objective: Provide a comprehensive view of key metrics across outlet types.
   - Chart Type: Matrix / Card.
